# Ravi Menu frontend

React + Vite. Use Node 22.22.0.

- `npm ci`: install locked dependencies.
- `npm run dev`: start the local UI.
- `npm run lint`: check code.
- `npm run build`: create the production bundle.
- `npm run test:e2e`: run Chrome browser tests with the disposable API fixture.

See the [project README](../README.md) for fixes, test setup, design references, and production blockers.
